# EHB 2026 submission checklist

Conference: 14th International Conference on e-Health and Bioengineering, hybrid, Iasi, 12–13 November 2026. Proceedings: Springer Nature / IFMBE, submitted to Web of Science. Topics this work maps to: wearable systems and sensors; biosignal processing; decision support and AI in medicine; biomechanics; medical devices; ethical aspects of e-health.

## Before EasyChair
- [ ] Paste `manuscript_blind.md` into the **blind** Springer Word template (no names, no ORCID, no grant IDs).
- [ ] Length 6–15 pages (6 is the indexed minimum). Extra pages: 80 EUR.
- [ ] USA English; no headers/footers/page numbers; no PDF security.
- [ ] Figures from `figures/` at ≥300 dpi (images) / vector PDF for line art (≥600 dpi if rasterized).
- [ ] Replace “Results” placeholders with numbers from `tables/ehb_results.json` after `make experiments`.
- [ ] PDF ≤ 2 MB for review.
- [ ] Double-check every citation against the publisher page.
- [ ] Ethics paragraph retained (prototype, not a medical device).
- [ ] After acceptance: authors template, copyright, camera-ready Word to paper@ehbconference.ro as instructed that year.

## Recommended talk framing (10 min)
Problem (DFU mechanics) → four-site rationale → features → grouped CV (not 99% IID) → limitations → prospective data.
