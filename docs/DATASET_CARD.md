# Dataset card: X-Step in-silico 4-FSR gait cohort

## Motivation
Paired daily insole recordings with ulcer endpoints are not in this repository. The cohort exists so gait/zone models can be tested with **subject-grouped** validation instead of inflated IID accuracy on identical sinusoids.

## Composition
- Modality: 8-channel plantar pressure (kPa), 25 Hz, 4 s windows
- Sites: L/R MET1, MET2, MET5, HEEL
- Labels: 9 gait patterns; 5 zone labels derived from pattern
- Subjects: 24 virtual participants with mass scale, FSR gain, offset, cadence bias, dropout
- Noise: Gaussian SD 3.5 kPa default; 3% label flips; mixed overload severity

## Collection
Generated by `xstep_ml.data.synthetic_gait.make_cohort`. Not human subjects. Not a substitute for a gait-lab or home-wear study.

## Preprocessing
Biomechanical features in `xstep_ml.biomechanics.extract_features`. No window from the same subject ID is used in both train and test under GroupKFold.

## Use
Train/evaluate plantar models. Do not cite as clinical incidence data.

## Maintenance
Repository scripts with seed 67. Regenerated by `scripts/run_ehb_experiments.py`.
